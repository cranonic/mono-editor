## TTF / WOFF File Icon Fonts

- Individual `.svg` file icons were replaced with local font files for Mono Studio:
  - `seti.woff` — Seti (Mono Default)
  - `devicon.ttf` — Devicon (Vibrant TTF)
  - `codicon.ttf` — Mono Vivid (Codicons Color TTF) & Minimal (Codicons Monochrome TTF)
- Extensions can still contribute custom file icon themes (font-based or SVG/PNG-based) via `contributes.iconThemes` or `mscode.themes.icon`.
